# AxoShader

AxoShader is an experimental Iris shader pack for Minecraft Java 1.21.1.

## Features (prototype)
- Warm daylight color grading
- Animated foliage/terrain vertex movement
- Animated water UVs and highlights
- Basic entity lighting
- Shadow pass files (experimental)

## Install
1. Install Iris for Minecraft 1.21.1.
2. Download the **AxoShader.zip** artifact from GitHub Actions.
3. Put the ZIP in `.minecraft/shaderpacks`.
4. Select AxoShader in Iris.

**Important:** This is an early prototype. It has not been verified in-game; compatibility and actual shadow rendering may require further fixes.
